# Checklist — Retirada de amianto

Usar después de `checklist-comun.md`.

```
IDENTIFICACIÓN DEL MATERIAL
────────────────────────────
□ ¿Qué elemento tiene amianto? → cubierta ondulada / placas fachada / canalones / bajantes / proyectado interior
□ ¿Es amianto friable (se desmenuza) o no friable (compacto, tipo fibrocemento)?
   ⚠ Si friable → marcar alerta de riesgo alto
□ ¿Hay análisis de fibras ya realizado? → sí / no / en curso
□ ¿El cliente tiene el Plan de Trabajo aprobado por la autoridad laboral?

MEDICIONES
──────────
□ Superficie a retirar (m²) o longitud (ml) si son canalones/bajantes
□ ¿Hay capas superpuestas de material? (afecta al peso y coste de gestión)
□ Estimación de toneladas (si se sabe): ____  [referencia: fibrocemento ≈ 15-20 kg/m²]

ACCESO
──────
□ ¿Cómo se accede? → andamio / plataforma / técnicas verticales / interior
□ ¿Hay espacio para zona de descontaminación (mínimo 6 m²)?

GESTIÓN DE RESIDUOS
────────────────────
□ ¿El cliente tiene preferencia de gestor autorizado o lo gestionamos nosotros?
□ ¿Se necesita cubierta nueva después de la retirada? (si sí → presupuesto combinado)

DOCUMENTACIÓN
─────────────
□ ¿Quién asume la comunicación a la autoridad laboral? → nosotros / cliente / técnico externo
□ ¿Se necesita certificado de destrucción para la propiedad o banco?
```

> **Nota:** Incluir siempre capítulo de Gestión de Residuos (código G) y mencionar empresa certificada RERA conforme al RD 396/2006.
