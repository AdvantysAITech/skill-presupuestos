# Checklist — Trabajos verticales (Vertical Projects)

Usar después de `checklist-comun.md`.

```
TRABAJO A REALIZAR
──────────────────
□ ¿Qué hay que hacer exactamente? → inspección / sellado / pintura / anclajes / limpieza / reparación puntual
□ ¿Hay zonas identificadas o hay que inspeccionar primero?
□ ¿Se necesita informe técnico o solo ejecución?

ALTURA Y ACCESO
───────────────
□ ¿Cuál es la altura máxima de trabajo?
□ ¿Hay puntos de anclaje existentes en cubierta o fachada?
   ⚠ Si no hay anclajes → marcar alerta
□ ¿Se puede acceder desde cubierta o solo desde fachada?
□ ¿Hay obstáculos: cornisas, balcones, marquesinas, cableado?

ENTORNO
───────
□ ¿Es zona urbana con tráfico o peatones bajo la zona de trabajo?
□ ¿El edificio está en casco histórico o es catalogado?
   ⚠ Si catalogado → marcar alerta
□ ¿Hay vecinos que puedan verse afectados? (comunicación previa)

DURACIÓN ESTIMADA
─────────────────
□ ¿Cuántos técnicos se estiman necesarios?
□ ¿El cliente tiene plazo de entrega? → fecha límite: ____
```

> **Nota:** Incluir siempre partida de Seguridad y Salud (código Y) con coste de medios de protección colectiva e individual.
