# Checklist — Cubiertas e impermeabilización

Usar después de `checklist-comun.md`.

```
MEDICIONES
──────────
□ Superficie total de cubierta (m²)
□ ¿Es cubierta plana, inclinada o mixta?
□ ¿Cuántos puntos de desagüe hay? (cazoletas)
□ Longitud de canalones (ml) y bajantes (ml) si se renuevan

ESTADO ACTUAL
─────────────
□ ¿Cuál es el sistema actual? → lámina bituminosa / teja / chapa / grava / otro
□ ¿Dónde están las filtraciones o humedades detectadas?
□ ¿Hay zonas con burbujeo o desprendimiento de lámina?
□ ¿Se va a levantar la impermeabilización existente o se aplica sobre ella?

SOLUCIÓN
────────
□ ¿Qué sistema se propone? → lámina bicapa / poliurea proyectada / monocapa autoadhesivo
□ ¿Se incluye formación de pendientes?
□ ¿Hay elementos singulares? → chimeneas, casetones, antenas, terrazas transitables

ACCESO
──────
□ ¿Se accede por interior del edificio o desde exterior?
□ ¿Se necesita grúa o pluma para subir materiales?
```
