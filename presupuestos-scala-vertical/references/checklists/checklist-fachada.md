# Checklist — Rehabilitación de fachada

Usar después de `checklist-comun.md`.

```
MEDICIONES
──────────
□ Superficie total de fachada (m²)  →  si no la sabe: nº plantas × longitud × altura por planta
□ ¿Hay más de una orientación / fachada? → superficie por cada una
□ Longitud de cornisas y molduras a tratar (ml) — si aplica
□ Longitud de vierteaguas a sustituir o sellar (ml) — si aplica
□ Nº de huecos (ventanas/puertas) para sellado perimetral

ESTADO ACTUAL
─────────────
□ ¿Qué patologías visibles hay? → fisuras / desprendimientos / humedades / eflorescencias / oxidación
□ ¿Hay zonas con revoco suelto o que suene a hueco?
□ ¿Se conoce el sistema de fachada actual? → enfoscado / monocapa / ladrillo visto / otro
□ ¿Hay elementos singulares complicados? → balcones volados, cornisas con relieve, rejillas, etc.

SOLUCIÓN Y ACABADO
───────────────────
□ ¿Qué sistema se va a proponer? → SATE/ETICS / revestimiento continuo / pintura elástica / fachada ventilada
□ ¿Color o acabado preferido por el cliente?
□ ¿Se incluye tratamiento de balcones o solo fachada vertical?

ACCESO Y MEDIOS AUXILIARES
───────────────────────────
□ ¿Qué tipo de acceso se necesita? → andamio tubular / plataforma elevadora / técnicas verticales
□ ¿Hay espacio en calle para instalar andamio o plataforma?
□ ¿La obra está en casco histórico o zona de difícil acceso?
□ ¿Cuántas semanas estimadas de alquiler de medios auxiliares?
□ ¿Se necesita licencia de ocupación de vía pública? (ayuntamiento)
```
