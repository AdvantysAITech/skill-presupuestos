# Checklist común — Todos los tipos de trabajo

Hacer estas preguntas siempre antes de las específicas por tipo.

```
DATOS DEL CLIENTE
─────────────────
□ ¿Nombre completo del cliente o comunidad?
□ ¿Dirección del inmueble / obra?
□ ¿Persona de contacto y teléfono?
□ ¿Email de envío del presupuesto?
□ ¿Tipo de cliente? → Comunidad de propietarios / Empresa / Administración / Particular

CONTEXTO DE LA VISITA
──────────────────────
□ ¿Quién hizo la visita y cuándo?
□ ¿Hay arquitecto o técnico implicado? (nombre + colegio si se sabe)
□ ¿El cliente ya tiene otros presupuestos? (competencia activa: sí / no / no sabe)
□ ¿Hay urgencia o fecha límite para recibir el presupuesto?
```
