# Estructura de capítulos típicos

## Scala Valencia (rehabilitación de fachadas)

Capítulos comunes y su orden recomendado:

1. **DEMOLICIÓN Y TRABAJOS PREVIOS** — Demolición de revestimiento, picado de enfoscado, retirada de elementos.
2. **FACHADA Y CERRAMIENTO** — Limpieza mecánica, pintura, fachada ventilada, sistema SATE, enfoscados.
3. **CARPINTERÍA Y CERRAJERÍA** — Reparación de carpinterías, sellados perimetrales, barandillas.
4. **CUBIERTAS** (si aplica) — Impermeabilización, sustitución de teja, canalones.
5. **REMATES Y ELEMENTOS SINGULARES** — Cornisas, molduras, balcones, pilares ornamentales.
6. **MEDIOS AUXILIARES** (si se factura aparte) — Andamio, redes, plataformas.
7. **GESTIÓN Y SEGURIDAD** — Plan de seguridad, gestión de residuos, certificados finales.

Códigos de partida (estándar CYPE):
- `DFF020` = Demolición de fachadas
- `DRS020` = Demolición de revestimientos
- `FZB010` = Limpieza mecánica
- `RFP010` = Pintura plástica exterior
- `FAL010` = Fachada ventilada
- `FCL010` = Sistema SATE

## Vertical Projects (trabajos verticales)

Capítulos comunes:

1. **INSPECCIÓN Y DIAGNÓSTICO** — Inspección visual integral, documentación fotográfica, informe técnico inicial.
2. **TRABAJOS POR DESCUELGUE / TÉCNICAS VERTICALES** — Sellados, reparaciones puntuales, aplicación de pinturas.
3. **MEDIOS AUXILIARES** — Plataformas elevadoras, andamio mixto, descuelgue por cuerda.
4. **PETOS, CASETÓN Y CUBIERTA** — Picado, enfoscado, impermeabilización en zonas altas.
5. **CAJA DE ESCALERA, BARANDILLAS Y ZAGUÁN** — Pintura interior, raspado, reparación.
6. **DESLUNADOS** — Trabajos en patios interiores con descuelgue.
7. **REHABILITACIÓN DE FACHADA** — Picado, enfoscado, pintura exterior.
8. **REHABILITACIÓN DE MEDIANERAS** — Reparación de paramentos contiguos.
9. **DOCUMENTACIÓN FINAL** — Informe técnico, certificados, garantías.

Códigos de partida VP (no CYPE estándar — internos):
- `PC-NN` = Petos y Cubierta
- `ES-NN` = Escalera
- `DL-NN` = Deslunados
- `FC-NN` = Fachada
- `MD-NN` = Medianeras
- `IN-NN` = Inspección
- `TV-NN` = Trabajos Verticales
- `DC-NN` = Documentación
